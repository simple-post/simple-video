# Working on Simple Video

This is the standalone `simple-post/simple-video` repository for the public `@simple-post/video` npm package. Releases use `video-v*` tags and `.github/workflows/release.yml`. Creating release tags, publishing packages, and changing repository visibility require maintainer authorization.

Use Node.js 24+. Run `npm test`, `npm run check`, `npm run format:check`, and `npm run check:package` for changes to the CLI/engine. Tests use fixtures and mocked APIs; do not make paid image requests unless the user authorizes them. Runtime setup downloads are separate from generation. Setup must show its plan and ask before installing in a terminal; automation requires explicit `setup --yes`. Preserve non-interactive `--json --no-input` operation, the stdout JSON / stderr progress contract in JSON mode, and readable terminal output by default. Declining setup or omitting unattended approval must have no filesystem/network side effects.

Keep code, docs, examples and the skill synchronized. The copy under `skills/simple-video` is installed directly from GitHub and bundled on npm. Paths must work outside this checkout. Use generic examples and keep personal paths, private media, credentials and runtime assets out of Git and npm artifacts. Preserve third-party notices and install DepthFlow separately under its own AGPL license.

Initialization must request explicit content, prompt for missing descriptions in a terminal, or require deliberate `--example`/`--local` selection. Key setup uses hidden input or explicit stdin/environment imports. Never put key values in command arguments, output, recipes or receipts. Preserve credential source precedence, private storage permissions and symlink checks. Test credential handling only with dummy keys and isolated config directories. Setup/login must offer native OS, explicit file, and environment-only modes. Native errors must fail closed, never trigger weaker storage. Secrets use IPC, never subprocess arguments or helper environment variables. Migration must verify the destination before removing the source. Gate releases on real macOS/Linux/Windows native-store tests.

Never silently replace DepthFlow with the CPU renderer. No generation command should upload or publish media.
